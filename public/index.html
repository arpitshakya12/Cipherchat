📘 CipherChat Quick User Guide

1. Multi-Device Recovery PIN & Storage

Aapke accounts aur encrypted messages permanent Neon Cloud DB (512 MB free) me save hote hain, jabki aapki encryption keys aur login session phone ki localStorage (~10 KB) me safe rehte hain.

2. Steganography Secret Image (+ → Stego)

Kisi normal photo ke pixels ke andar aapka AES-256 encrypted text chhup jata hai. Receiver photo par Reveal dabakar andar ka message padh sakta hai aur photo download bhi kar sakta hai.

3. Reply, Forward & Sealed Sender

Har message ke neeche ↩ Reply aur ↪ Forward buttons diye gaye hain. Sealed Sender ON karne par server database me sender_id = 0 save hota hai.

4. App Lock + Decoy PIN & .cipher Backup

Settings (⚙) me jakar Decoy PIN set karein—agar koi zabardasti app khulwaye to Decoy PIN daalte hi ek khali Safe Mode screen khulegi.
